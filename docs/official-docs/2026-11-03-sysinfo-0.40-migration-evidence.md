  <https://github.com/GuillaumeGomez/sysinfo/blob/v0.40.1/migration_guide.md>

## Decisions and preserved behavior

- Keep the public `collect_portable` return contract. On `System`
  initialization failure, CPU and memory observations explicitly carry the
  failure and the process list is empty, rather than reporting invented cores
  or zero memory. Independently available OS metadata is retained.
- Map `Unsupported` to `Observation::Unsupported`, permission-denied I/O to
  `Denied(FileRead)`, other I/O to `Error(Io)`, and non-I/O errors to
  `Error(InvalidOutput)`. Never persist or log raw dependency error messages.
- All three OS metadata getters use the same Result mapping, with no
  success-shaped OS-name fallback. Sanitize successful strings at the
  collector boundary.
- In snapshots, any unavailable native portable fact marks `portable` as
  partial instead of completed. GPU availability remains outside this native
  completeness decision; its separate adapter is unchanged.
- Retain one System instance, two selective CPU/memory process refreshes
  separated by `MINIMUM_CPU_UPDATE_INTERVAL`, per-core CPU normalization,
  ephemeral usage observations, deterministic CPU/memory/name ordering, the
  20-process cap, basename redaction, and the summary-only schema.
- The shared Unix/Windows descendant-termination test helper propagates
  initialization failure as an explicit test error and refreshes only its
  synthetic child PID. It cannot mistake initialization failure for absence
  of a surviving process. Timeout budgets and process-group execution are
  unchanged.

  compilation again.
